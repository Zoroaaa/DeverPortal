## 是什么

一个个人博客系统。前端 React 18，后端 Hono 4，前端放 Cloudflare Pages，后端跑 Workers，数据分在 D1、KV、R2 三处。

写作走 Markdown，文章按专栏、分类、标签三个维度组织，另有置顶、上下篇、相关推荐、浏览量、SEO 字段和密码访问。读者侧有评论（嵌套最多 5 层）、点赞、收藏、阅读历史、站内通知和私信；作者侧有一个后台，管文章、专栏、评论审核、用户、分类标签、站点配置和统计。通知可以按类型单独开关、设免打扰时段，再汇总成每日或每周邮件。

> 证据：README「核心特性」「功能模块」；`backend/src/routes/` 目录；`database/schema-v1.1-base.sql` 里的 posts_fts。

## 实现要点

单仓 npm workspaces：`frontend/`（React + Vite + Zustand + React Router + Tailwind）、`backend/`（Hono on Workers）、`database/` 三个按版本排序的 schema。后端分 `routes / services / repositories / middleware / durableObjects`，文章查询单独抽了数据访问层（commit `a922f80`）。

几个改动能看出取舍：

- 限流从 KV 计数换成 Durable Object 原子计数（commit `794fded`），KV 最终一致会漏计。
- 点赞和文章标签写入改成 `db.batch`（commit `43f8449`）。
- 评论渲染接 DOMPurify 白名单（commit `9366e39`）。
- 每日 / 每周邮件汇总合并成一个 `*/15` 的 cron（commit `c0d5af9`），后来修了 scheduled 没挂到 default export、触发器不生效的问题（commit `06d13b1`）。
- 前端按路由懒加载（commit `e27361d`），页面拆成编排层、hooks 和展示组件（commit `52112f8`、`9b67a16`）。

部署链路写在 workflow 里：main 分支推送 → 根目录 `npm ci` → typecheck → `scripts/migrate.sh blog-db --remote` → wrangler deploy。

> 证据：根 `package.json` 的 workspaces；`backend/src/` 目录分层；上述 commit；`.github/workflows/deploy.yml`；`backend/wrangler.toml` 的 Durable Object 绑定和 `crons = ["*/15 * * * *"]`。

## 怎么用

自己部署前有几项绕不开：

- Node 20+（前后端 `package.json` 的 engines 都是 `>=20`）。Cloudflare 账号和 wrangler 4。
- 建自己的 D1、KV、R2，把 `backend/wrangler.toml` 里的 `database_id`、KV `id`、bucket 名换掉，`FRONTEND_URL` 和 `STORAGE_PUBLIC_URL` 也要改。
- `JWT_SECRET` 必填。GitHub OAuth 和 Resend 是可选项，不配就少了第三方登录和邮件。
- 3 个 schema 要按顺序跑；`scripts/migrate.sh` 已经固定了这个顺序，语句是幂等的，可以重复执行。

```bash
git clone https://github.com/Zoroaaa/personal-blog.git
cd personal-blog
npm ci                                  # 根 lockfile，workspaces 一起装前后端

npx wrangler d1 create blog-db          # 返回的 id 填进 backend/wrangler.toml
npx wrangler kv namespace create CACHE  # 同上
npx wrangler r2 bucket create blog-storage

bash scripts/migrate.sh blog-db         # 本地库；打生产加 --remote

cd backend
npx wrangler secret put JWT_SECRET
cd ..

npm run dev:backend                     # :8787
npm run dev                             # :5173，读 frontend/.env 的 VITE_API_URL
```

只想看效果的话，https://blog.wort.uk/ 是线上实例，不用部署。
