样张说明 / DESIGN RATIONALEB · BLUEPRINT

视觉主张

网站是一份产品图纸集：米色纸、细蓝网格、图号与规格表。装饰全部带注释含义，没有纯装饰。

记忆点

每件作品是一张带图号的"FIG."图纸，配手绘感图解；页脚是制图信息栏（SHEET / REV / SCALE）。

代价

三个方向里维护成本最高：网格、刻度、图号都要成体系，否则立刻显得廉价；文档正文必须降到纯纸底，否则阅读被网格干扰。
