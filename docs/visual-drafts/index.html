DeverPortal · 视觉方向 · 三选一

先挑气质，再定设计系统

三个方向都基于同一份真实内容（7 个作品）做成首页样张。看气质差异，不看细节完成度——选定后我会把该方向做成完整 token 与组件。

我的建议：B 工程蓝图。它和"作品 + 说明书 + 版本记录"的结构同构，记忆点来自页面结构而不是贴上去的装饰，扩到文档页也立得住。

A / EDITORIAL01

纸本印刷

把网页当一本高端印刷刊物：纸白底、超大字、严格栅格、单色印刷红。

适合什么气质
冷静、克制、有品位；像设计工作室的作品集。
代价与风险
信息密度最低；产品超过 10 个必须有筛选；离开大标题就显得素。

B / BLUEPRINT02

工程蓝图

网站是一份产品图纸集：米色纸、细蓝网格、图号、规格表、手绘感图解。

适合什么气质
工程感、认真、可考据；像在读一份设备说明书。
代价与风险
维护成本最高；装饰多易吵；文档正文必须能关掉网格。
打开样张 B →
C / HARD EDGE03

硬边色块

每个作品占一块高饱和色卡：2px 黑边、零圆角、偏移实心阴影。

适合什么气质
直接、有活力、敢冒险；像贴满标签的工作台。
代价与风险
长文疲劳；色彩纪律一松就廉价；气质偏"玩"，削弱工程严肃感。
